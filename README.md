CineSuggest is a modern, personalized movie recommendation web application designed to help users discover movies based on their interests and viewing preferences. The application integrates the TMDB API to provide real-time movie information, including posters, ratings, genres, cast, trailers, and similar movies. Users can search and explore movies, view detailed information, rate movies, maintain a watchlist, and receive personalized recommendations based on their favorite genres and interactions. The project is built with a React frontend and Node.js/Express backend, with the architecture designed to support MongoDB for persistent user data and JWT authentication in future versions. The recommendation system initially uses content-based filtering and can later be enhanced with Python, FastAPI, and machine-learning techniques.
